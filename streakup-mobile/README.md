# 📱 StreakUp Mobile (React Native + Expo)

Gamified Habit Tracker & Routine Planner mobile application frontend.

---

## 🚀 Quick Start (Testing on Mobile Phone or Browser)

### 1. Install Dependencies
```powershell
cd streakup-mobile
npm install
```

### 2. Start Expo Development Server
```powershell
npx expo start
```

### 3. Run on your Phone
1. Install **Expo Go** app from:
   * **Android:** [Google Play Store](https://play.google.com/store/apps/details?id=host.exp.exponent)
   * **iOS:** [Apple App Store](https://apps.apple.com/app/expo-go/id982107779)
2. Scan the QR code shown in your terminal with Expo Go (Android) or Camera app (iOS).
3. The app will immediately load on your phone!

Or press `w` in terminal to run directly in your web browser!

## 💡 Key Features Implemented

* 🔥 **Streak Tracker & Flame Engine:** Visual daily streak counter with level progression.
* 🛡️ **Streak Shield Protection:** Protects streaks when you take a rest day or miss a habit.
* 📺 **Rewarded Video Ad Simulation (AdMob):** When a streak breaks, watch a 15-30s video to instantly revive the streak.
* 👑 **Paywall & Pro Membership:** 
  * Free limit enforced (Max 4 habits).
  * High-converting Paywall for Monthly (₹79/mo) and Annual (₹499/yr) plans.
  * Instant unlock of unlimited habits and 5 bonus shields.
* 🏆 **Badges & Achievements:** 7 initial badges (First Step, 7-Day Warrior, 30-Day Master, Level 5, etc.).
* 📊 **Consistency Heatmap:** 8-week visual activity matrix (similar to GitHub commits).
* ⚡ **Zero-Friction Offline/Demo Mode:** Built-in instant preview with pre-loaded habits, so you can test all features without having to set up databases first.
